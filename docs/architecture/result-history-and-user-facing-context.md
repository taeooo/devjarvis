# Result History and User-Facing Context Cleanup

## 문제 정의
결과 히스토리가 충분히 보이지 않고, 우측 상태 패널에 사용자 관점에서 중복되거나 불필요한 개발 지표가 노출되었습니다.

## 해결 방향
- 결과 패널을 현재/히스토리로 분리합니다.
- 히스토리 영역은 독립 스크롤 리스트로 표시합니다.
- Project/RAG 중복 타일은 제거하고 프로젝트 선택 상태는 Project 카드에서만 보여줍니다.
- 결과 카드의 제목/요약 잘림을 완화합니다.

## 보안 기준
이번 변경은 UI 노출 정보 정리이며 파일 읽기/전송 경계는 변경하지 않습니다.
